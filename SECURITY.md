# Security Policy

Thanks for taking the time to look at BitPilot's security. This document
explains how to report a vulnerability, what's in scope, and what to expect
in response.

## Reporting a vulnerability

**Do not open a public GitHub issue for a security report.** Public reports
give attackers a head start before a fix can ship.

2. **Email**: write to `jokunlade@gmail.com` with the
   subject prefix `[bitpilot-security]`.
Please include, to the extent you can:

- A clear description of the issue and where it lives (file path, route,
  commit SHA).
- Steps to reproduce, or a minimal proof-of-concept.
- The impact you believe it has (what an attacker can read, modify, deny,
  or escalate to).
- Any suggested fix or mitigation.

We will acknowledge your report within **3 business days** and aim to send a
substantive update at least every **7 days** until the issue is resolved.
